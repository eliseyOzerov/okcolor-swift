## Overview

Oklab was designed by Bjorn Ottosson and introduced in the article [A perceptual color space for image processing](https://bottosson.github.io/posts/oklab/). The color picker spaces and gamut helpers implemented by this package are based on Ottosson's public reference material.

This Swift package is licensed under MIT. The repository license also includes a third-party notice for the original Oklab, OkHSL, OkHSV, and gamut helper reference code.
